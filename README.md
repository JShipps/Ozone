## Quick start

Open `index.html` in your browser. To run it on a local server instead:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

Because it's static, you can deploy it anywhere: GitHub Pages, Netlify, Cloudflare Pages, or any web host.
